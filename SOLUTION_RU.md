# Решение IS-Lab2 на MATLAB

Задание: [serackis/IS-Lab2](https://github.com/serackis/IS-Lab2).

- `lab2_main.m`: основное задание, 20 примеров, сеть 1–8–1, tanh в скрытом слое, линейный выход, обратное распространение ошибки вручную.
- `lab2_surface.m`: дополнительное задание, поверхность двух переменных, сеть 2–8–1.
- `DEFENSE_RU.md`: объяснения, формулы, вопросы для защиты.

Откройте нужный `.m`-файл в MATLAB и нажмите Run. Данные создаются внутри программы. Дополнительные Toolbox не нужны. После выполнения будут выведены коэффициенты, ошибки и графики.

Статическая проверка штатным анализатором MATLAB R2026a пройдена без замечаний.

В формуле из README исправлен баланс скобок: на 2 делится вся сумма `1 + 0.6*sin(2*pi*x/0.7) + 0.3*sin(2*pi*x)`. Для дополнительного задания выбрана поверхность `0.5 + 0.25*sin(pi*x1)*cos(pi*x2)`.

У основной сети лимит 100000 эпох, у поверхности — 10000. Обе останавливаются раньше при MSE < 0.0001. Если достигнут лимит, ориентируйтесь на фактическую напечатанную MSE.

Численная проверка алгоритмов отдельно в Python дала MSE около 0.000100 и 0.000107 соответственно. Это не результаты MATLAB: его установленная версия не запустилась из рабочей среды (`File system inconsistency`). Инициализация Python отличается, результаты MATLAB могут быть другими. Перед защитой выполните скрипты в MATLAB.
