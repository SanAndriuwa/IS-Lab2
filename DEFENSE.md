## Lab1: объяснение за одну минуту

### Повторное использование первой работы

Готовые признаки уже загружаются из исходного Data.txt. Альтернативно функция `bayes_from_lab1(P, T, Ptest)` получает непосредственно массивы первой работы: P имеет две строки (цвет, округлость) и по столбцу на обучающий объект; T содержит его класс. Ptest хранит признаки проверочных фруктов в таком же формате. Выход y — столбец предсказанных классов. Подробный пример — в README дополнительного задания. Для сравнения с персептроном у обоих методов должны совпадать признаки и разделение данных. При вызове с P вместо Ptest оценивается обучение, а не независимая проверка.

«У каждого фрукта есть два числовых признака: цвет и округлость. По трём яблокам и двум грушам я нахожу средние значения и дисперсии признаков для каждого класса. Затем для нового объекта вычисляю, насколько его признаки характерны для яблока и для груши. Выбираю класс с большей оценкой. Метод называется наивным, потому что предполагает независимость признаков внутри класса. Остальные восемь объектов использую для проверки, а не для обучения».

### Как работает код

- X: таблица из 13 строк и 2 признаков. d: правильные классы, 1 для яблока, −1 для груши.
- train: строки 1, 2, 3, 10, 11. test: строки 4–9, 12, 13. Они не пересекаются.
- classes = [1 -1]: порядок классов в массиве оценок.
- mu: средние значения двух признаков для двух классов, матрица 2×2.
- sigma2: дисперсии, то есть квадраты стандартных отклонений. Это НЕ стандартное отклонение sigma.
- prior: доли классов в обучающей выборке: 3/5 для яблок и 2/5 для груш.
- score: логарифмическая оценка каждого класса. Она может быть отрицательной и не является нормированной вероятностью.
- max выбирает класс с большей оценкой.

Формула Байеса:

```text
P(c | x) = p(x | c) * P(c) / p(x)
```

Знаменатель одинаков при сравнении классов, поэтому его можно не считать. При предположении условной независимости признаков:

```text
p(x1, x2 | c) = p(x1 | c) * p(x2 | c)
```

Числовые признаки моделируются нормальным распределением:

```text
p(xj | c) = exp(-(xj-mu)^2 / (2*sigma2)) / sqrt(2*pi*sigma2)
score(c) = log(P(c)) + log(p(x1 | c)) + log(p(x2 | c))
```

Программа считает последнюю формулу сразу, без промежуточного умножения маленьких чисел. Логарифм возрастает, поэтому класс-победитель остаётся тем же. Значения плотности распределения могут быть больше 1: это не вероятность одного точного значения непрерывного признака.

### Результат и его смысл

Независимая численная проверка этих формул на исходных данных дала 5/5 на обучении и 7/8 на проверке (87,5%). Восемь проверочных объектов — очень мало: одна ошибка меняет точность сразу на 12,5 процентного пункта. Нельзя по этому результату утверждать, что программа узнаёт любые фотографии фруктов. Она получает уже вычисленные признаки.

### Частые вопросы

**Почему классификатор «наивный»?** Предполагается независимость цвета и округлости при известном классе. В реальных данных это предположение может выполняться лишь приблизительно.

**Чем отличается от персептрона?** Персептрон меняет веса по ошибкам и строит линейную границу. Байес оценивает распределения признаков и выбирает более вероятный класс; граница у такого гауссовского классификатора может быть нелинейной.

**Где обучение, если нет эпох?** В вычислении средних, дисперсий и долей классов. Эти параметры находятся непосредственно по обучающим данным.

**Почему var(..., 1, 1)?** Первый аргумент 1 после данных задаёт деление на N для оценки дисперсии, второй — вычисление по строкам отдельно для каждого столбца-признака.

**Зачем ограничение 1e-8?** Если признак одинаков у всех примеров класса, дисперсия равна нулю. Малое нижнее ограничение предотвращает деление на ноль и логарифм нуля.

**Почему нельзя обучать на всех данных и на них же доказывать качество?** Это показывает только качество на знакомых объектах. Проверку надо проводить на объектах, не участвовавших в оценке параметров.

**Как улучшить качество?** Собрать больше обучающих объектов и проверить признаки. Нельзя подбирать параметры по этим восьми объектам и затем называть их независимой проверкой.

## Lab2: объяснение за одну минуту

«Я обучаю сеть приближать значения функции. На вход подаётся одно число x, затем восемь нейронов вычисляют tanh от взвешенного входа со смещением. Выходной нейрон складывает их ответы с весами и добавляет своё смещение. Я сравниваю ответ с правильным значением и с помощью обратного распространения ошибки обновляю все веса. После обучения сеть вычисляет ответ через tanh и найденные коэффициенты, без вызова исходной синусоидальной формулы».

### Данные и устройство сети

Обучающих точек ровно 20: linspace(0, 1, 20). Целевая функция:

```text
d(x) = (1 + 0.6*sin(2*pi*x/0.7) + 0.3*sin(2*pi*x)) / 2
```

В исходном README нарушен баланс скобок. Здесь принято, что на 2 делится вся сумма в числителе. Это явно отмечено в коде.

Сеть имеет 1 вход → 8 скрытых нейронов tanh → 1 линейный выход. Число входов и число примеров — разные вещи: на каждом шаге один вход получает очередное число из 20.

```text
h_j = tanh(w1_j*x + b1_j)
y = w2_1*h_1 + ... + w2_8*h_8 + b2
```

- w1: 8×1, веса от входа к скрытым нейронам.
- b1: 8×1, отдельное смещение каждого скрытого нейрона.
- h: 8×1, ответы скрытых нейронов.
- w2: 1×8, веса от скрытого слоя к выходу.
- b2: одно число, смещение выхода.
- Всего 8 + 8 + 8 + 1 = 25 обучаемых параметров.
- eta = 0.02: шаг обучения.
- epoch: один полный проход по 20 примерам. За эпоху выполняется 20 обновлений.
- rng(1): фиксирует последовательность случайных чисел для повторяемого запуска в MATLAB.

### Обратное распространение по шагам

1. Вычислить h и y — прямой проход.
2. Найти e = d − y.
3. Передать ошибку к скрытым нейронам, учитывая выходные веса и производную tanh.
4. Обновить веса и смещения обоих слоёв.
5. После эпохи заново вычислить ответы с итоговыми весами и средний квадрат ошибки.

```text
L = 0.5*(d-y)^2
delta_j = e*w2_j*(1-h_j^2)
w2_j <- w2_j + eta*e*h_j
b2   <- b2   + eta*e
w1_j <- w1_j + eta*delta_j*x
b1_j <- b1_j + eta*delta_j
```

Знак «плюс» правильный: e определена как d − y. Производная L по выходному весу равна −e*h, а градиентный спуск вычитает производную. Два минуса дают плюс.

Важно: delta вычисляется со СТАРЫМИ выходными весами до их обновления. Все производные должны соответствовать одному прямому проходу.

Производная tanh равна 1 − tanh²; в коде это 1 − h.^2. У линейного выхода производная равна 1.

Пример одного изменения: если d=0.7, y=0.5, h_j=0.4 и eta=0.02, то e=0.2 и выходной вес увеличится на 0.02×0.2×0.4=0.0016.

### Графики и остановка

MSE = mean((d − y).^2). Это средний квадрат ошибки, не процент точности. Чем ближе к нулю, тем точнее совпадают значения на выбранных точках.

Обучение заканчивается при MSE < 0.0001 или после 100000 эпох. Ограничение числа эпох предотвращает бесконечное обучение. Достижение предела не означает достижения заданной ошибки: смотреть нужно на напечатанную MSE.

Синяя линия — формула, красная — сеть, кружки — обучающие точки. Плотная сетка из 201 точки показывает качество между обучающими значениями. Она включает и часть обучающих точек, поэтому это проверка приближения на интервале, а не полностью независимый тест на новых данных. График semilogy показывает MSE в логарифмическом масштабе; при последовательных обновлениях ошибка не обязана уменьшаться на каждой эпохе.

### Частые вопросы

**Почему нужна нелинейная активация?** Несколько линейных слоёв сводятся к одному линейному преобразованию и не смогут хорошо описать волнистую функцию.

**Почему выход линейный?** Задача — предсказать числовое значение. Линейный выход не ограничивает его интервалом активации скрытого слоя.

**Зачем bias?** Он сдвигает активацию независимо от входа. Без него возможности сети ограничены.

**Почему случайные веса?** Они позволяют скрытым нейронам начать обучение по-разному. При одинаковых начальных весах нейроны могут оставаться одинаковыми и дублировать друг друга.

**Что будет при большом eta?** Обновления могут перескакивать минимум, ошибка может колебаться или расти. Слишком маленький eta замедляет обучение.

**Что такое backpropagation?** Применение цепного правила производных от выхода к предыдущим слоям. Он вычисляет градиенты; сами параметры обновляются градиентным спуском.

**Почему сеть не просто вычисляет исходный sin?** Sin используется только для получения правильных ответов и сравнения. Предсказание сети использует tanh и обученные веса.

**Можно ли подавать x вне [0, 1]?** Вычислить ответ можно, но точность вне обучающего интервала не гарантирована. Это экстраполяция.

**Как понимать переобучение?** Сеть может хорошо совпасть с обучающими точками и плохо работать между ними или на новых данных. Поэтому кроме учебной MSE смотрим плотную сетку; для практической задачи нужны отдельные данные для выбора параметров и окончательной проверки.

**Чем отличаются .* и *?** .* — умножение соответствующих элементов, * — матричное умножение. .^2 возводит каждый элемент в квадрат. Апостроф транспонирует действительные массивы: столбец становится строкой.

## Дополнительная поверхность

Выбрана функция двух переменных, так как конкретная поверхность в задании не задана:

```text
d(x1,x2) = 0.5 + 0.25*sin(pi*x1)*cos(pi*x2)
```

Обучение идёт на сетке 10×10, то есть на 100 парах координат. Сеть: 2 входа → 8 tanh → 1 линейный выход. W1 имеет размер 8×2, потому что у каждого скрытого нейрона два входных веса. Всего 16 + 8 + 8 + 1 = 33 параметра.

Формула скрытого слоя: h = tanh(W1*p + b1), где p — столбец [x1; x2]. Обновление W1 = W1 + eta*delta*p' создаёт матрицу 8×2. В остальном алгоритм тот же. Проверочная сетка 41×41 позволяет сравнить форму поверхностей; это тоже плотная проверка того же интервала, не полностью независимая выборка. Лимит — 10000 эпох, целевая MSE — 0.0001.
